# RedDot

桌面半透明圆点 + 按日期管理、可收起的母级/子级待办 + 一键跳转。13 套主题，卡片式界面。

📄 **[《RedDot 沉浸式学习手册》PDF](docs/RedDot-manual.pdf)** — 特色、沉浸式学习的作用、完整用法（11 页）。想先弄懂它为什么有用，看这份就够了。

🌐 **[在线精简版](https://shixin0816.github.io/RedDot/)** — 5 屏看完：三个设计、三条机制、四步上手。手机打开也合适。

📦 **[下载 RedDot.apk](dist/RedDot.apk)** — 约 71 KB，Android 7.0+，debug 签名，可直接安装。

## 它是什么

- **桌面红点**：悬浮在其他应用之上，半透明红圈 + 白点。单击弹「今日待办」，双击隐藏（通知栏留一个恢复入口），可以拖到顺手的位置。
- **母级 + 子级**：母级是分类（英语学习），底下一组子级（背 20 个单词 / 精听一集播客…）。点母级标题整组收起，右侧 ＋ 直接往这组加一条。
- **第三级是跳转目标**：每条子级可以绑一个精确链接（某个博主主页 / 某个视频）。
- **按日期管理**：每条待办挂在某一天，主页可以 ‹ › 前后翻日期；红点弹窗永远只显示「今天」的待办，不会混进昨天的任务。
- **精确跳转**：跳转目标是真实链接，点一下直接打开对应内容，不用每次再找。
- **捕获目标**：三条路，① 在小红书 / B站 里「分享」→ 选 RedDot；② 点编辑页「⧉ 从剪贴板粘贴链接」，复制完链接回来点一下；③ 点「去捕获链接」，切到目标页复制链接，再点红点气泡确认。
- **选 App 可搜索**：选跳转应用时有搜索框，最近跳转过的应用排在「最近跳转」分组里。
- **13 套主题**：霓虹红 / 赛博青 / 暮光紫 / 极光绿 / 蒸汽波 / 警示黄 / 复古琥珀 / 军绿 / 深海 / 蓝图 / 樱花粉 / 墨水屏 / 红白极简。主页右上角调色盘切换，全局立即生效。

## 怎么出 APK

**方式零：本机脚本（已验证可用）**

```bash
bash build_apk.sh
```

产物是根目录的 `RedDot.apk`，debug 签名，可直接安装。脚本用 JDK + build-tools + android.jar 手工打包，不依赖 Gradle；因为 aapt2 处理不了中文路径，源码会先同步到 `C:/rd` 再编译。

**方式一：Android Studio**

1. 装 Android Studio（含 JDK 17 和 Android SDK）。
2. `File → Open` 选这个 `RedDot` 目录。
3. 等 Gradle 同步完成，`Build → Build Bundle(s)/APK(s) → Build APK(s)`。
4. APK 在 `app/build/outputs/apk/debug/app-debug.apk`。

**方式二：GitHub Actions（不用本地环境）**

1. 把 `RedDot` 目录推到 GitHub 仓库（`main` 分支）。
2. 打开仓库 `Actions` 页，跑 `Build RedDot APK`。
3. 跑完后在 workflow 的 Artifacts 里下载 `RedDot-apk`。

## 装到手机上

1. 传 APK 到手机，点安装，允许「安装未知来源应用」。
2. 打开 RedDot → 打开「在桌面显示圆点」→ 授予**悬浮窗权限**（显示在其他应用上层）。
3. Android 13+ 会问通知权限，建议允许，否则圆点被双击隐藏后只能回 App 里恢复。

### 国产 ROM（MagicOS / MIUI / ColorOS）必须做

只开悬浮窗是不够的，系统会把后台服务清掉、圆点消失。App 主页底部有「圆点被清掉了？点这里看设置步骤」，也可以按下面手动设：

1. **悬浮窗**：设置 → 应用和服务 → 应用管理 → RedDot → 权限 → 悬浮窗 → 允许
2. **应用启动管理**：设置 → 应用和服务 → 应用启动管理 → RedDot → 关掉「自动管理」，把「自启动」「关联启动」「后台活动」三项都打开
3. **忽略电池优化**：设置 → 应用和服务 → 特殊访问权限 → 电池优化 → RedDot → 不允许
4. **最近任务加锁**：多任务界面把 RedDot 卡片下拉加锁，一键清理时不会被带走

其他国产 ROM（小米 / OPPO / vivo）同理：自启动 + 后台运行 + 电池白名单。

## 已知限制

- **无法读取别的 App 当前页面**。Android 不给这个权限，所以捕获只能是「复制链接 / 分享链接」这一条路，拿不到「你正在看哪个博主」。
- **小红书链接能否直达原生 App** 取决于小红书自己声明了哪些 scheme；B站 `bilibili://video/BVxxxx` 规则稳定，已做映射。落地情况需要真机校准一次。
- 微信内打开的链接可能被拦在浏览器里，这是微信的策略，不是本应用的问题。

## 剪贴板读不到链接？这是系统限制，不是 bug

Android 10 起，只有「当前获得焦点的应用」才能读剪贴板，后台应用读到的永远是空值。所以：

- 捕获面板不会在 `onCreate` 里读，而是等窗口真正拿到焦点后再读，读不到会每 200ms 重试一次，最多约 3 秒。
- 面板里有输入框，长按可以手动粘贴；还有「重新读取剪贴板」按钮。
- 如果文案是「剪贴板里是「xxx」，没找到链接」，说明复制的内容不是链接 —— 要在目标页点「分享 → 复制链接」，只截图不算。
- 部分国产 ROM 可能对剪贴板访问有额外隐私限制，这种情况下用「⧉ 从剪贴板粘贴链接」或分享到 RedDot 最稳。

## 已知限制（补充）

- 桌面圆点靠前台服务 + 悬浮窗维持，部分系统仍可能在某些场景下杀掉服务；杀掉后重开 App 即可恢复。
- 主题切换会重建界面，列表滚动位置会回到顶部。
